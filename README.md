## 一、准备工作

### 1.1 硬件清单

| 部件 | 规格 / 说明 | 备注 |
|------|-------------|------|
| 主控板 | ESP32（含 BLE，如 ESP32-DevKitC / ESP32-WROOM-32） | 支持 BLE 4.2 |
| 电机驱动 | DRV8833 | NSLEEP 接 GPIO3 |
| 电机 ×2 | 带编码器（霍尔 / 光电） | 左右各一个 |
| 姿态传感器 | MPU6050 | I2C 接口 |
| LED | WS2812（1 颗，GPIO48） | 板载即可 |
| 电池 | 3.7V~8.4V 锂电池组 | 匹配电机额定电压 |
| 手机 | Android 8.0 及以上 | 需支持 BLE |

### 1.2 引脚接线表（**必须与代码一致**）

| 功能 | GPIO | 说明 |
|------|------|------|
| 左电机 IN1 / IN2 | 4 / 5 | DRV8833 输入 |
| 右电机 IN3 / IN4 | 6 / 7 | DRV8833 输入 |
| DRV8833 NSLEEP | 3 | 拉高使能 |
| 左编码器 A / B | 8 / 9 | 上拉输入 |
| 右编码器 A / B | 10 / 11 | 上拉输入 |
| MPU6050 SDA | 1 | I2C |
| MPU6050 SCL | 2 | I2C |
| WS2812 | 48 | 板载 LED |

> ⚠️ 如需修改引脚，请同步修改 `motor_control.c` / `encoder.c` / `mpu6050.c` 中的宏定义。

### 1.3 软件环境

| 工具 | 版本建议 | 用途 |
|------|----------|------|
| **ESP-IDF** |  v5.5.1  | 编译烧录 ESP32 固件 |

## 四、连接与使用

### 4.1 开机顺序

1. 先检查元器件是否插稳，方向是否正确，再打开小车电源，先开芯片开关，再开电机开关。两个可以间隔半秒开。
2. 观察 LED：
   - **绿灯闪烁** = 待连接
   - **彩虹灯** = 已连接（正常使用状态）

### 4.2 手机连接 BLE

1. 打开 App → 进入 **"遥控"** 或 **"自动行驶"** 页面
2. 确认 **"设备名称"** 显示为 `ESP32_Car`（默认值）
3. 点击 **"连接"** 按钮
4. 等待 2~5 秒：

| 状态提示 | 含义 | 下一步 |
|---------|------|--------|
| ✅ **已连接** | 连接成功 | 可以操作 |
| ⏱ **扫描超时** | 3 次仍失败 | 见下方排查 |
| ❌ **连接失败** | 配对中途断开 | 重试或重启小车 |

> 💡 首次连接失败一次属正常现象，**再点一次"连接"** 通常就成功。

### 4.3 遥控操作

| 操作 | 说明 |
|------|------|
| 摇杆（单/双模式） | 速度 = 前后推杆，转向 = 左右推杆 |
| 方向按钮 | 上/下/左/右 + 停止 |
| 归零按钮 | 摇杆复位，暂停发送（松手不发控制包） |

> **遥控前必须保证小车放在平整地面、** 且 MPU6050 已完成静止校准（上电后 3 秒内不要动小车）。

### 4.4 自动导航（可选）
**自动导航的控制参数没有调好，可以自行去设置-自动导航这里设置**
1. 进入 **"自动行驶"** 页面
2. 在**地图上长按**添加目标点，或点击 **"添加当前位置"**
3. 至少添加 2 个点
4. 点击 **"开始导航"**
5. 小车将按纯跟踪算法（Pure Pursuit）自动追踪路径

> 导航过程中点击 **"停止"** 可立即停车。

### 4.5 路径点保存 / 加载

- **保存**：点击"保存" → 写入 `waypoints.json`
- **加载**：点击"加载" → 从文件系统选择 JSON
- **导出**：点击"导出" → 通过微信/QQ 等分享 JSON 文件

## 五、参数调节（可选）

进入 **"设置"** 页面可调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 设备名称 | `ESP32_Car` | BLE 广播名称，需与小车一致 |
| 最大速度 | 2.2 m/s | 遥控速度上限 |
| 最大转向 | 50 °/s | 遥控转向角速度上限 |
| 导航最大速度 | 1.5 m/s | 自动导航速度上限 |
| 到点判定半径 | 1.5 m | 距目标点小于此值即到站 |
| 校准时间 | 2 秒 | 静止校准所需时长 |
| 转向增益 | 2.0 | 越大转向越激进 |
| 摇杆模式 | 双摇杆 | 单摇杆 / 方向键 |
| 服务器地址 | 空 | 远程中转（一般无需设置） |

> 🔧 修改完记得点 **"保存"** 按钮。

## 六、常见问题排查

### Q1：小车连不上，日志显示 `Advertising started` 但手机搜不到

**排查顺序**：

1. 手机蓝牙是否**已开启**？
2. Android 12+ 是否授予了 **"附近设备"** 权限？（设置 → 应用 → 本 App → 权限）
3. 手机上是否**还有其他 App 占用 BLE 连接**？关闭它们
4. 手机**靠近小车（1 米内）** 再试
5. 重启小车（断电 → 重新上电）再试

### Q2：手机显示"扫描超时"，但小车 LED 已变彩虹灯

说明 **CCCD 订阅响应丢失**。
需要重新编译烧录小车，可能会解决。如果还是不行请联系我。

### Q3：能连上但摇杆无反应

1. 听电机有没有发出哔哔的噪音，如果有，就尝试左右旋转小车，查看是否旋转。如果没有旋转，可能是固定电机的螺丝过长卡住内部转子。
2. 打开app的设置-控制参数，查看速度倍率这一栏数值，正常应为2-6，太低会使电机无法转动。
3. 检查日志（ESP-IDF monitor）是否有 `WRITE_EVT handle=42` 打印：
   - **有** → ESP32 收到指令，问题在电机或接线
   - **没有** → 手机端 `isReadyToSend` 未置 true，重新连接

### Q4：小车原地打转 / 姿态不稳

1. **上电后 3 秒内保持静止**（MPU6050 需要陀螺仪校准）
2. 检查电池电压是否过低
3. 若持续打转，进入设置调小 **"最大转向"**

### Q5：红色 / 紫色 LED 闪烁

| 颜色 | 含义 |
|------|------|
| **紫色闪 5 次** | MPU6050 检测失败 → 检查 I2C（GPIO1/GPIO2）接线和上拉电阻 |
| **红色常亮** | 初始化完成（正常） |
| **红灯闪** | 初始化失败 → 查看 monitor 日志定位问题 |

### Q6：烧录报错 `A fatal error occurred: Failed to connect to ESP32`

1. 按一下 ESP32 板上的 **BOOT 键**，再点 flash
2. 或先按住 **BOOT**，再按一下 **EN/RST**，松开 EN，再松开 BOOT
3. 检查 USB 数据线是否为**数据线**（有些是纯充电线）
4. 换一个 USB 口（避开前置 USB 或 USB 集线器）

### Q7：编译报 `CMake Error: Could not find led_strip`

在项目目录执行：

```bash
idf.py add-dependency "espressif/led_strip^2.5.0"
idf.py fullclean
idf.py build
```


## 七、快速上手流程（TL;DR）

```
① 电脑装 ESP-IDF v5.3 + USB 驱动
        ↓
② 接线对照"1.2 引脚接线表"
        ↓
③ idf.py add-dependency "espressif/led_strip^2.5.0"
        ↓
④ idf.py set-target esp32 && idf.py build
        ↓
⑤ idf.py -p COM3 flash monitor
        ↓
⑥ 看到 "System ready." + 绿色 LED 慢闪 = 小车端 OK
        ↓
⑦ Android Studio 打开 App 项目 → 编译安装
        ↓
⑧ 授予蓝牙 + 定位权限
        ↓
⑨ App 里输入 "ESP32_Car" → 点"连接"
        ↓
⑩ LED 变彩虹灯 = 全链路成功，可以遥控！
```
